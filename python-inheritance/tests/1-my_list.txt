============================
Tests for 1-my_list module
============================

Import the class:

>>> MyList = __import__('1-my_list').MyList

Unsorted list is printed sorted:

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]

The original list is not modified:

>>> print(my_list)
[1, 4, 2, 3, 5]

Empty list:

>>> MyList().print_sorted()
[]

Negative numbers and duplicates:

>>> my_list = MyList([3, -1, 3, 0, -5])
>>> my_list.print_sorted()
[-5, -1, 0, 3, 3]

Already sorted list:

>>> MyList([1, 2, 3]).print_sorted()
[1, 2, 3]

Reverse sorted list:

>>> MyList([3, 2, 1]).print_sorted()
[1, 2, 3]

It is a real list:

>>> issubclass(MyList, list)
True
>>> my_list = MyList([2, 1])
>>> len(my_list)
2
