# python-import_modules

Python project on importing modules and handling command-line arguments.

| File | Description |
|---|---|
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports the functions of `calculator_1.py` and prints the results of a and b |
| `2-args.py` | Prints the number and list of its arguments |
| `3-infinite_add.py` | Prints the sum of all its arguments |
| `4-hidden_discovery.py` | Prints the names defined by the compiled module `hidden_4.pyc` |
| `5-variable_load.py` | Imports variable `a` from `variable_load_5.py` and prints it |

All scripts run with `python3` and are not executed when imported.
