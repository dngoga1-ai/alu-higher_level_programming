# python-network_1

Python project covering HTTP requests with `urllib` and `requests`:
headers, POST data, error codes, JSON APIs and Basic Authentication.

## Requirements

- Python 3 (interpreter: `/usr/bin/python3`)
- Files end with a new line and start with `#!/usr/bin/python3`
- Code follows the PEP 8 style (`pycodestyle`)
- All files are executable
- `requests` package installed (`pip3 install requests`)

## Tasks

| File | Description |
|------|-------------|
| `0-hbtn_status.py` | Fetches a status URL with `urllib` |
| `1-hbtn_header.py` | Displays the `X-Request-Id` header (`urllib`) |
| `2-post_email.py` | Sends a POST request with an email (`urllib`) |
| `3-error_code.py` | Displays the body or the HTTP error code (`urllib`) |
