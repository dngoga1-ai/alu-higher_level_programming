# python-exceptions

Python project covering exception handling: `try` / `except` / `finally`
and raising exceptions.

## Requirements

- Python 3 (interpreter: `/usr/bin/python3`)
- Files end with a new line and start with `#!/usr/bin/python3`
- Code follows the PEP 8 style (`pycodestyle`)
- All files are executable

## Tasks

| File | Description |
|------|-------------|
| `0-safe_print_list.py` | Prints x elements of a list, returns the number printed |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()`, returns success |
| `2-safe_print_list_integers.py` | Prints the first x elements of a list, integers only |
| `3-safe_print_division.py` | Divides 2 integers and prints the result in `finally` |
| `4-list_division.py` | Divides 2 lists element by element |
| `5-raise_exception.py` | Raises a `TypeError` |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message |
