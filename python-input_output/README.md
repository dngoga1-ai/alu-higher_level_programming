# python-input_output

This project covers file input and output in Python: reading, writing and
appending text files with the `with` statement, JSON serialization and
deserialization (`json` module), command-line arguments (`sys.argv`), and
converting class instances to dictionaries.

## Requirements

- Python 3 (Ubuntu 20.04 LTS), files end with a new line
- First line of every file: `#!/usr/bin/python3`
- Code follows the `pycodestyle` style
- Modules, classes and functions are documented
- All files are executable

## Files

| File | Description |
| ---- | ----------- |
| `0-read_file.py` | Reads a UTF8 file and prints it |
| `1-write_file.py` | Writes a string to a file, returns characters written |
| `2-append_write.py` | Appends a string to a file, returns characters added |
| `3-to_json_string.py` | Returns the JSON string of an object |
| `4-from_json_string.py` | Returns the object represented by a JSON string |
| `5-save_to_json_file.py` | Saves an object to a file as JSON |
| `6-load_from_json_file.py` | Loads an object from a JSON file |
| `7-add_item.py` | Adds arguments to a list saved in `add_item.json` |
| `8-class_to_json.py` | Returns the dictionary description of an object |
| `9-student.py` | `Student` with `to_json()` |
| `10-student.py` | `to_json(attrs)` with an attribute filter |
| `11-student.py` | Adds `reload_from_json()` |
| `12-pascal_triangle.py` | Returns Pascal's triangle of size n |
