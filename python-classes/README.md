# python-classes

This project introduces classes and objects in Python: defining a class,
private attributes, properties (getters and setters), validation, and
instance methods. Every task builds a `Square` class, adding features step
by step.

## Requirements

- Python 3 (Ubuntu 20.04 LTS), files end with a new line
- First line of every file: `#!/usr/bin/python3`
- Code follows the `pycodestyle` style
- Modules, classes and methods are documented
- No module imports allowed
- All files are executable

## Files

| File | Description |
| ---- | ----------- |
| `0-square.py` | Empty class `Square` |
| `1-square.py` | `Square` with a private `size` (no validation) |
| `2-square.py` | Adds `size` type and value validation |
| `3-square.py` | Adds the `area()` method |
| `4-square.py` | Adds `size` getter and setter (property) |
| `5-square.py` | Adds `my_print()` to print the square with `#` |
| `6-square.py` | Adds a `position` property and prints with offset |
