# python-everything_is_object

This project explores how Python treats everything as an object: `id()` and
`type()`, mutable versus immutable objects, aliasing, integer
pre-allocation, and how arguments are passed to functions.

## Requirements

- Python 3 (Ubuntu 20.04 LTS), files end with a new line
- First line of Python files: `#!/usr/bin/python3`
- Code follows the `pycodestyle` style
- No module imports allowed

## Files

- `0-answer.txt` to `28-answer.txt`: short answers to the quiz tasks
  (there is no task 19 answer file, it is a Python script)
- `19-copy_list.py`: returns a copy of a list
