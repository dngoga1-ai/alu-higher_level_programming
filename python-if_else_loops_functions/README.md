# Python - if/else, loops, functions

This project contains Python scripts that practice conditional statements, loops, and functions.

## Requirements

- Ubuntu 20.04 LTS
- Python 3
- pycodestyle 2.7.*

## Files

- `0-positive_or_negative.py`: Identifies positive, negative, or zero numbers.
- `1-last_digit.py`: Prints information about the last digit of a random number.
- `2-print_alphabet.py`: Prints the lowercase alphabet.
- `3-print_alphabt.py`: Prints the alphabet except `e` and `q`.
- `4-print_hexa.py`: Prints numbers in decimal and hexadecimal.
- `5-print_comb2.py`: Prints numbers from 00 to 99.
- `6-print_comb3.py`: Prints unique combinations of two digits.
- `7-islower.py`: Checks whether a character is lowercase.
- `8-uppercase.py`: Prints a string in uppercase.
- `9-print_last_digit.py`: Prints and returns the last digit of a number.
- `10-add.py`: Adds two numbers.
- `11-pow.py`: Calculates a number raised to a power.
- `12-fizzbuzz.py`: Implements the FizzBuzz exercise.
