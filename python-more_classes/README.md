# python-more_classes

This project goes deeper into Python classes and objects: properties with
validation, class attributes versus instance attributes, `__str__` and
`__repr__`, `__del__`, static methods, and class methods. Every task builds a
`Rectangle` class, adding features step by step.

## Requirements

- Python 3 (Ubuntu 20.04 LTS), files end with a new line
- First line of every file: `#!/usr/bin/python3`
- Code follows the `pycodestyle` style
- Modules, classes and methods are documented
- No module imports allowed
- All files are executable

## Files

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | Empty class `Rectangle` |
| `1-rectangle.py` | Private `width` and `height` with validated properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | Adds `__str__` to draw the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` usable with `eval()` |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Adds the `number_of_instances` class attribute |
| `7-rectangle.py` | Adds the `print_symbol` class attribute |
| `8-rectangle.py` | Adds the static method `bigger_or_equal()` |
| `9-rectangle.py` | Adds the class method `square()` |
